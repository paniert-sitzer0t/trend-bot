# Pionex Trend-Rotation-Bot (Paper)
Alle 8 Stunden: Coins nach Betrag der 24h-Bewegung ranken, Signale 24h/7d/30d prüfen (2 von 3 entscheiden Long oder Short),
max. 3 Positionen, Gewichtung nach inverser Volatilität, unveränderte Positionen werden gehalten (spart Gebühren).
Short ist nur simuliert, Pionex bietet per API kein Shorten. Updates holt `update.sh` per Timer aus GitHub.
